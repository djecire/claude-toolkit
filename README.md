# evan-toolkit

Private Claude Code plugin marketplace holding Evan's personal skills, agents and commands, so every Claude (Mac, Claude cloud, Terry's computer) loads the same toolkit.

Install:

    claude plugin marketplace add djecire/claude-toolkit
    claude plugin install evan-toolkit@evan-toolkit

Source of truth is `~/.claude/{skills,agents,commands}` on Evan's Mac; re-sync with `sync.sh`.
